# Revio — План проекта

## Что это
SaaS для фрилансеров: загружаешь макеты, отправляешь ссылку клиенту, клиент без регистрации ставит метки на картинках и пишет комментарии. Фрилансер видит все правки в реальном времени и копирует их списком.

## Текущий статус: MVP v2 (упрощённая версия без кругов правок)

**Решение (утверждено):** убрали всю логику «кругов правок / пакетов / заморозки / статусов клиента». Клиент сразу подтверждает правки — они появляются у фрилансера автоматически. Одна ссылка на проект.

---

## Жизненный цикл проекта (MVP v2)

```
Создание → Загрузка макетов → Ссылка активна →
Клиент тыкает в картинки и пишет комментарии (без регистрации) →
Фрилансер видит правки в реальном времени → копирует текстом
```

### Детали:

1. **Создание** (1 шаг)
   - Название (обязательно) + короткое описание (по желанию)
   - Статус: `waiting_for_images`

2. **Загрузка макетов**
   - Пустое состояние: большой dropzone (пунктирная рамка)
   - Кликаешь → file picker → файлы появляются как список-миниатюры с нумерацией
   - Внизу: «Загрузить пакет» → модалка подтверждения → загрузка в Cloudinary
   - Статус: `in_progress`, появляется ссылка для клиента

3. **Клиент открывает ссылку** (`/review/[id]`)
   - Никакой регистрации. Сразу видит картинки
   - Тыкает в место правки → вводит текст → маркер сохраняется сразу
   - Есть общий комментарий и список уже добавленных правок

4. **Фрилансер видит правки**
   - Обновление в реальном времени (onSnapshot + polling)
   - Просмотр картинок с точками, список правок, «Скопировать все правки текстом»
   - Просмотр картинок с зумом (+/−) и стрелками

5. **Замена макетов**
   - Кнопка «Заменить макеты» → модалка предупреждения → новые файлы
   - Все старые маркеры клиента удаляются вместе с заменой

## Тарифы

- **Free:** 3 активных проекта, 10 изображений на проект
- **Pro:** безлимит проектов и изображений, 299 ₽/мес
- Оплаты НЕТ — на кнопке «Оплатить» показывается Telegram (@Gafti): «напишите нам — включим Pro вручную»
- Лимит Free проверяется при создании проекта: если активных ≥ 3 → модалка с предложением Pro

## Страницы

### `/` — Главная (список проектов)
- Поиск, фильтрация
- Карточки: название, описание, счётчик изображений, дата
- Меню: переименовать, закрепить, архив, удалить
- Создание: визард 1 шаг (название + описание)

### `/project/[id]` — Детали проекта (freelancer view)
- Пустое состояние → dropzone для загрузки
- Есть картинки → ссылка (копировать), «Скопировать все правки», «Заменить макеты», список правок, список изображений
- Просмотр изображения: стрелки, зум, маркеры с текстами
- Полноэкранный просмотр (лупа)
- Шапка: назад + название + шестерёнка (настройки)

### `/project/[id]/settings` — Настройки проекта
- Название + описание, сохранить
- Архив / Удалить

### `/review/[id]` — Страница клиента
- Без авторизации. Показывает имя проекта
- `waiting_for_images` → «Макеты ещё не загружены»
- `in_progress` → MarkerCanvas (маркеры сохраняются сразу при клике)

### `/login` — Авторизация (Google)
### `/notifications` — Уведомления
### `/pricing` — Тарифы (Free 3 проекта / Pro 299₽, FAQ, кнопка → Telegram)
### `/settings` — Глобальные настройки профиля

## Архитектура данных

### Project (Firestore: `projects`)
| Поле | Тип | Описание |
|------|-----|----------|
| `ownerUid` | string | UID фрилансера |
| `name` | string | Название проекта |
| `description` | string | Описание |
| `clientName` | string | Имя клиента (не используется в UI v2) |
| `clientContact` | string | Контакт клиента (не используется в UI v2) |
| `imageUrls` | string[] | URL картинок (Cloudinary) |
| `currentRound` | number | Зарезервировано (всегда 1 в v2) |
| `roundsTotal` | number | Зарезервировано (всегда 5 в v2) |
| `roundsLeft` | number | Зарезервировано (всегда 5 в v2) |
| `limitMessage` | string | Зарезервировано |
| `isLocked` | boolean | Зарезервировано (всегда false в v2) |
| `pinned` | boolean | Закреплён |
| `archived` | boolean | В архиве |
| `status` | enum | `waiting_for_images` / `in_progress` |
| `createdAt` | Timestamp | Дата создания |
| `updatedAt` | Timestamp | Дата обновления |

> Поля раундов оставлены в модели для совместимости со старой базой. UI их не показывает.

### Marker (Firestore: `markers`)
| Поле | Тип | Описание |
|------|-----|----------|
| `projectId` | string | ID проекта |
| `round` | number | Всегда 1 в v2 |
| `type` | `point` / `general` | Точечная метка или комментарий |
| `x?` | number | Позиция X (0-1, relative) |
| `y?` | number | Позиция Y (0-1, relative) |
| `text` | string | Текст правки |
| `createdAt` | Timestamp | Дата создания |

### Notification (Firestore: `notifications`)
| Поле | Тип | Описание |
|------|-----|----------|
| `ownerUid` | string | UID фрилансера |
| `projectId` | string | ID проекта |
| `projectName` | string | Название проекта |
| `type` | enum | `revisions_submitted` / `project_completed` |
| `message` | string | Текст уведомления |
| `read` | boolean | Прочитано |
| `createdAt` | Timestamp | Дата создания |

### UserProfile (Firestore: `users`)
| Поле | Тип | Описание |
|------|-----|----------|
| `displayName` | string | Имя |
| `email` | string | Email |
| `plan` | `free` / `pro` | Тариф |
| `onboardingCompleted` | boolean | Прошёл онбординг |
