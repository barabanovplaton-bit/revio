## Проект

Revio — SaaS для фрилансеров-дизайнеров. Дизайнер загружает макеты, кидает клиенту ссылку, клиент без регистрации ставит правки (маячки) на картинках. Дизайнер видит их в реальном времени.

Стек: Next.js 16 + React 19 + TS, Tailwind, Framer Motion, Firebase (Auth + Firestore), Cloudinary (картинки), Vercel (деплой).

Одна ссылка на проект. Клиент ставит маячки. Дизайнер видит правки. Есть **раунды правок** (итерации макетов), история версий, лимиты по тарифу (Free 5 / Pro безлимит, докупка), промо-блок, холст с маячками. Готово к пушу и проверке на проде.

---

## Принятые решения

- **Раунды правок**: «Заменить макеты» начинает новый раунд. Старые макеты и правки сохраняются в истории (`packageHistory`). Ничего не стирается.
- **Лимит на Free**: счётчик раундов при создании проекта (1–5, по умолчанию 5). Докупка раундов — суммарно не больше 5.
- **Лимит на Pro**: без ограничения раундов.
- **Маячки (правки)**: без лимита количества.
- **Pro включается вручную** через Telegram @Gafti (оплаты нет). Кнопки «Pro» ведут на `/pricing`.
- **Маркетинг при исчерпании** (Free): промо-блок «Раунды закончились» с кнопками «Добавить раунд» / «Перейти на Pro».
- **Холст** (просмотр макетов в кабинете): кнопка «Перейти на холст», тумблер «С маячками / Без маячков».
- Cloudinary-переменные должны быть заданы в Vercel (env) — иначе загрузка падает.
