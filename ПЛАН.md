## Проект

Revio — SaaS для фрилансеров-дизайнеров. Дизайнер загружает макеты, кидает клиенту ссылку, клиент без регистрации ставит правки (маячки) на картинках. Дизайнер видит их в реальном времени и отмечает сделанные.

Стек: Next.js 16 (App Router, Turbopack) + React 19 + TypeScript, Tailwind, Framer Motion, Firebase (Auth + Firestore), Cloudinary (картинки), Vercel (деплой, автодеплой после пуша).

## Текущий статус: MVP v2 — раунды правок (собрано)

Одна ссылка на проект. Клиент ставит маячки прямо на фото. Дизайнер видит правки и заменяет макеты (новый раунд). Есть история версий, лимиты по тарифу (Free 5 / Pro безлимит, докупка), промо-блок, единый просмотрщик-«холст» с панелью правок, фильтрами и галочками «сделано».

---

## Принятые решения

- **Раунды правок**: «Заменить макеты» начинает новый раунд. Старые макеты и правки сохраняются в истории (`packageHistory`). Ничего не стирается.
- **«Заменить макеты» доступна, только когда клиент прислал правки** (есть маркер в раунде или `clientSubmitted`). Иначе кнопка приглушена; при нажатии — подсказка. Если раунды кончились — «Раунды исчерпаны».
- **«Скопировать все правки» — убрана** (не нужна).
- **Холст = тот же просмотрщик, что у клиента, но read-only** (нельзя добавлять/удалять): точки привязаны к ФОТО, зум/драг двигают фото вместе с точками, листание, тумблер «С маячками / Без маячков», левая панель (на телефоне — снизу) со списком правок.
- **Панель правок**: нумерация по порядку создания (вычисляется на лету — удаление не ломает), фильтры «Порядок / Страницы / Длина», галочка «сделано» (поле `done`), клик по строке — переход на страницу маркера + подсветка.
- **Маркеры привязаны к конкретной картинке** (`imageIndex`). Старые маркеры без `imageIndex` показываются на всех страницах (backward compat).
- **Клиент**: клик по фото → форма «Опишите правку» (снизу), кнопка «Общий комментарий», может удалять свои правки. Счётчик «осталось раундов» в шапке.
- **Лимит на Free**: счётчик раундов при создании проекта (1–5, по умолчанию 5). Докупка раундов — суммарно не больше 5.
- **Лимит на Pro**: без ограничения раундов.
- **Маячки (правки)**: без лимита количества.
- **Pro включается вручную** через Telegram @Gafti (оплаты нет). Кнопки «Pro» ведут на `/pricing`.
- **Промо-блок при исчерпании** (Free, 5/5): «Раунды закончились» → «Перейти на Pro».
- Cloudinary-переменные должны быть заданы в Vercel (env) — иначе загрузка падает.

## Жизненный цикл проекта

```
Создание → Загрузка макетов → Ссылка активна →
Клиент тыкает в картинки и пишет комментарии (без регистрации) →
Клиент нажимает «Готово» (clientSubmitted=true) →
Дизайнер видит правки на холсте, отмечает сделанные →
«Заменить макеты» → новый раунд (правки в историю) →
...
```

## Страницы

- `/` — список проектов: поиск, карточки (название, счётчик изображений, дата), меню (переименовать/закрепить/удалить), визард создания со счётчиком раундов, модалка лимита Free (3 проекта).
- `/project/[id]` — кабинет: загрузка/замена макетов, ссылка для клиента, статус раундов, «Перейти на холст», «Заменить макеты», история версий, список правок раунда, список изображений.
- `/review/[id]` — страница клиента без регистрации: MarkerCanvas (клик по фото → правка), «Общий комментарий», «Готово» → модалка «Правки отправлены!», блокировка при исчерпании раундов.
- `/login` — авторизация (Google + email-ссылка).
- `/notifications` — уведомления.
- `/pricing` — тарифы (Free/Pro, FAQ), кнопка → Telegram.
- `/settings` — профиль (имя, тариф).

## Архитектура данных

### Project (`projects`)
| Поле | Тип | Описание |
|------|-----|----------|
| `ownerUid` | string | UID фрилансера |
| `name`, `description` | string | Название, описание |
| `clientName`, `clientContact` | string | Не используется в UI |
| `imageUrls` | string[] | Текущий пакет (Cloudinary) |
| `packageHistory` | ProjectPackage[] | Старые пакеты `{round, imageUrls, createdAt}` |
| `currentRound` | number | Текущий раунд правок |
| `roundsTotal`, `roundsLeft` | number | Всего / осталось раундов |
| `extraRoundsAdded` | number | Сколько докуплено |
| `clientSubmitted` | boolean | Клиент нажал «Готово» в текущем раунде |
| `limitMessage` | string | Текст при исчерпании |
| `isLocked` | boolean | Блокировка правок клиента |
| `pinned`, `deleted` | boolean | Закреплён / мягко удалён (слот лимита НЕ освобождается) |
| `status` | enum | `waiting_for_images` / `in_progress` / `exhausted` |
| `createdAt`, `updatedAt` | Timestamp | Даты |

### Marker (`markers`)
| Поле | Тип | Описание |
|------|-----|----------|
| `projectId` | string | Проект |
| `round` | number | Раунд |
| `type` | `point` / `general` | Точечная правка / общий комментарий |
| `x`, `y` | number | Позиция на фото (0-1, relative) |
| `imageIndex` | number | Номер картинки, к которой привязана точка |
| `done` | boolean | Отметил ли фрилансер как сделанную |
| `text` | string | Текст правки |
| `createdAt` | Timestamp | Дата (по ней — нумерация точек) |

### Notification (`notifications`)
| Поле | Тип | Описание |
|------|-----|----------|
| `ownerUid`, `projectId`, `projectName` | string | Адресат и проект |
| `type` | enum | `revisions_submitted` / `project_completed` |
| `message`, `read`, `createdAt` | … | Текст, прочитано, дата |

### UserProfile (`users`)
| Поле | Тип | Описание |
|------|-----|----------|
| `displayName`, `email` | string | Профиль |
| `plan` | `free` / `pro` | Тариф |
| `onboardingCompleted` | boolean | Прошёл онбординг |

## Тарифы

- **Free**: 3 проекта (считаются все созданные, включая удалённые), 10 изображений на проект, 5 раундов на проект (докупка до 5), маячки без лимита.
- **Pro**: безлимит проектов/изображений/раундов, 299 ₽/мес. Оплаты НЕТ — на кнопке «Оплатить» показывается Telegram (@Gafti): «напишите нам — включим Pro вручную».
